# 9. Architecture decisions

Part of the [Arc42 architecture documentation](README.md).

Decisions are recorded as ADRs in [docs/adr/](../adr/README.md); that index is the list, and this section does not copy it. New ADRs start from [the template](../templates/adr.md). An ADR that is still *proposed* is not yet a source of truth ([AGENTS.md](../../AGENTS.md#source-of-truth)).

Decision LH-1 of the former target architecture (destructive reset, no recovery key) is [ADR-0003](../adr/0003-destructive-reset.md). How the documentation itself is structured is [ADR-0010](../adr/0010-arc42-architecture-documentation.md).
